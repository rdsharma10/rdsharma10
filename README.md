---

## Selected Work

### AI Email Intelligence Pipeline

Classifies inbound email and routes qualified leads into Salesforce automatically.

| | |
|---|---|
| **Problem** | Leads arriving by email were triaged manually and inconsistently. |
| **Solution** | Gmail Pub/Sub push events trigger a Node.js service. Google Gemini classifies each message and extracts lead intent. Qualified leads are created in Salesforce. |
| **Stack** | Node.js, Express, Gmail API, Google Pub/Sub, Google Gemini, Salesforce REST API |

### Twilio and Salesforce Telephony Layer

Two-way voice and SMS integration that lives inside Salesforce.

| | |
|---|---|
| **Problem** | Calls and texts happened outside the CRM, so activity was not tracked against records. |
| **Solution** | Call routing, automatic task creation, and SMS tracking tied to Salesforce records, with a custom LWC dashboard for call and message activity. |
| **Stack** | Twilio, Apex, Lightning Web Components, Node.js, PM2, DigitalOcean |
